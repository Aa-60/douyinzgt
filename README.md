# 一体化运营工作台（WorkBuddy Station）

一个纯前端、零后端的一体化运营工作台：把「导航台 + 选品库 + 爆款内容架构 + 爆品打磨 + 知识库」放在一个页面里，适合跨境电商（1688 / YouTube / 抖音）内容运营日常使用。蓝色主题、中文界面、移动端友好。

## 一、它能做什么

| 模块 | 功能 |
|------|------|
| 🏠 工作台首页 | 分组导航入口（可自定义）、欢迎卡片、快速开始 |
| 📊 数据面板 | 读 `data/*.json` 渲染卡片/图表（示例：抖音选品），配置驱动 |
| 🗂 资源中枢 | 列出站内 `resources/manifest.json` 中的资源文件 |
| 🛍 选品库 | 录入商品（ID/链接/店铺/价格/佣金/评分/风险）、时间+风险+评分筛选、分页、导出/导入 JSON/CSV |
| 🧩 爆款内容架构 | 记录爆款视频/笔记的标题、钩子、文案结构、卖点、价格带 |
| 💥 爆品打磨 | 对选品做多角度打磨，支持「从选品库一键导入」减少重复录入 |
| 🎯 对标账号 | 展示低等级带货账号、成交证据、可学结构、关联商品与风险边界 |
| 📚 知识库 | 收藏选品/运营/文案/工具类知识点 |

## 二、技术栈与约束

- **纯静态**：HTML/CSS/JS 全部内嵌在 `index.html`，无后端、无数据库。
- **数据存储**：所有录入数据默认存在**浏览器 localStorage**，不自动上云。换设备 / 清缓存会丢；要同步请用「导出 JSON」下载，再导入到另一台设备的浏览器。
- **登录**：纯前端访问密码锁（SHA-256 比对），防普通访客，非真安全。默认密码 `yem2026`，可在左下「修改密码」改（仅对当前浏览器生效）。

## 三、目录结构

```
station/
├── index.html        # 全部页面与逻辑（CSS/JS 内嵌）
├── config.json       # 首页导航分组（改这里就能加/删首页入口）
├── data/             # 数据面板读取的 JSON（示例 selection.json）
└── resources/        # 资源中枢读取的 manifest.json + 资源文件
```

`data/benchmark-accounts.json` 保存公开的对标账号快照。页面中的“内容可学”和“商品可跟”是两套结论；证据过期、商品不合格或原片未核验时会明确标注，不把历史快照当作实时推荐。

## 四、本地运行

方式一（最简单）：双击 `index.html` 直接用浏览器打开（已做 file:// 兼容）。
方式二（推荐）：在项目目录起本地服务，浏览器开 `http://localhost:端口`。

```bash
cd station
python -m http.server 8080
```

## 五、部署上线

# GitHub → Settings → Pages → 已指向 main 分支 / 根目录

### CloudStudio（一键公网）
把本项目目录作为静态站点发布即可。

⚠️ **公开仓库 = 站点文件公开**：任何放 `data/`、`resources/` 的真实业务数据都会被公开索引。敏感数据请留在本地，只用脱敏后的内容。

## 六、给接手 AI / 开发者的说明

**如何改首页导航**：编辑 `config.json` 的 `navGroups`，每个分组含 `title / icon / links[]`，链接 `url` 填 `#` 表示占位。

**如何加一个新「本地录入页」**（复用现有模式）：
1. 在 `index.html` 的侧边栏 `<nav>` 加一个 `<button class="menu-item" data-view="xxx">`
2. 加一个 `<section id="view-xxx" class="view">` 表单 + 表格
3. 在 JS 里复制 `selectionItems` 的「load / save / render + 分页 + 筛选 + 导出」逻辑，换字段即可
4. 在 `switchView` 的 `map`、`titles`、`load()` 里登记新 view

**关键逻辑位置**：
- 密码锁：JS 顶部 `sha256()` + 登录态 `ws_authed` / 密码哈希 `ws_pwd_hash`
- 选品去重：提交时检查 14 天内同一 `pid`（`addItem` 内）
- 评分筛选：`renderSelection` 里按 `pscore` 过滤

**尚未完成 / 可优化**（优先级）：
- P0：数据备份无脑化（一键导出所有模块到本地）
- P0：手机端响应式优化（侧边栏在窄屏下需折叠）
- P1：搜索框覆盖各页表格内容
- P1：爆品导入隐藏已导入商品
- P1：数据面板读取选品库真实数据（当前是示例）
- P1：默认密码改成专属哈希再上线

## 七、重要提醒

- 数据不上云的「断点」：公网版和本地浏览器数据是分开的。公网上录的只存访客浏览器，本地录的只存本机。
- 密码锁是「防君子」级别，挡不住查看源码的人；敏感数据不要放公网。
