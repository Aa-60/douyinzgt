☁️ 云端同步

把工作台数据备份到你的 GitHub 仓库 Aa-60/douyinzgt（文件 data/workbench-data.json），换浏览器、换设备也能一键恢复，刷新前也能随时备份。

如何获取 Token：
  1. GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens → Tokens (classic)。
  2. 生成新 token，勾选 repo 权限（或 Fine-grained 选本仓库的 Contents 读写）。
  3. 复制 token 粘贴到上方并点“保存”。token 仅存在本机浏览器，不会上传。

⚠️ 个人 token 等同仓库写入权限，请勿在公共电脑保存或勾选自动同步；如有泄露可在 GitHub 立即撤销。
